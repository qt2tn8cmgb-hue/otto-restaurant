# OTTO: сайт + Telegram-бот для меню

Бот меняет цены, названия, удаляет и добавляет блюда. Сайт сам подхватывает изменения (файл menu.json), код трогать не нужно.

## 1. Создайте бота
1. В Telegram откройте @BotFather → /newbot → получите **токен**.
2. Узнайте свой Telegram ID у @userinfobot. Если админов несколько, возьмите ID каждого.

## 2. Запустите на сервере
Нужен сервер с Python 3.10+ (VPS, Render, Railway и т.п.):
```
pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
export ADMIN_IDS="ваш_id,id_второго_админа"
python bot.py
```
Сайт откроется на порту 8080 (адрес сервера или ваш домен). Бот и сайт работают в одном процессе.

## 3. Как пользоваться
Напишите боту /start. Выберите раздел → блюдо → «Изменить цену», «Изменить название» или «Удалить». Кнопка «Добавить блюдо» создаёт новую позицию. Изменения видны на сайте сразу после обновления страницы.

Боту отвечают только ID из ADMIN_IDS. Меню хранится в menu.json: делайте его резервную копию.
